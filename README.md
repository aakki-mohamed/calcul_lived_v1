# Life Calculator v1

## Description
This is a simple Python project that calculates how long a person has lived based on their age.  
It converts age into months, weeks, days, hours, minutes, and seconds.

## Features
- Takes user age as input
- Converts age into different time units
- Displays results in a clear formatted output

## Example Output
- Months lived
- Weeks lived
- Days lived
- Hours lived
- Minutes lived
- Seconds lived

## Technologies
- Python 3

## Purpose
This project was created to practice Python basics, arithmetic operations, and user input handling.
